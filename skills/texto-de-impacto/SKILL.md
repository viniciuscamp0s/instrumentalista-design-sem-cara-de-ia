# Texto de impacto

Base: `instrumentalista-design-sem-cara-de-ia/docs/06-copy-na-arte.md`, seção "Texto de alto impacto".

1. Leia o texto inteiro e entenda a intenção. Conte os movimentos (afirmação, contraste, conclusão, convite): o
   resultado tem os mesmos, mais afiados.
2. Corte palavra solta, conector fraco, repetição. Nunca uma ideia que o autor queria ali.
3. Ritmo de martelo: curta para afirmar, um pouco mais longa para desenvolver, curta para fechar.
4. Troque o abstrato pelo concreto: frase de pôster motivacional vira fato específico ou sai.
5. Vocabulário simples, peso alto. Sem jargão de bastidor (funil, algoritmo, nome de método).
6. Proibidos no texto de arte: travessão, antítese vazia ("Não é X, é Y"), número não confirmado, escassez falsa.
7. Ficou mais curto e mais fraco? Cortou músculo. Volte. Frase de vínculo num texto para alguém é estrutura e fica.
8. Entregue o antes e o depois, e uma linha dizendo o que mudou.
