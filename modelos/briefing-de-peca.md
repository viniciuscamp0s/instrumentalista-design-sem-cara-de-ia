# Briefing de peça (uma por peça ou por pack)

> A IA preenche a partir da ficha da marca e do pedido, e mostra antes de escrever o prompt.

| Campo | Resposta |
|---|---|
| Marca | |
| Objetivo | anúncio (clique) / orgânico (salvar, compartilhar, seguir, comentar) |
| Formato | anúncio estático / card único / carrossel de N cards |
| Público desta peça | quente (já conhece) / frio (nunca ouviu falar) |
| Ângulo | dor / prova / oferta / antes e depois / bastidor / evento real |
| Desfecho (carrossel) | salvamentos / compartilhamentos / seguidores / comentários |
| Arquétipo (carrossel) | Sistema / Fórmula / Coleção / Autópsia / Preenchível / Confissão |
| Gênero visual | |
| Plano de destaque | o que é maior, o que é âncora, o que é secundário |
| Referência | nenhuma (peça original) / arquivo |
| Números usados e fonte | |
| Anexos para o gerador | logo (variante), referência, fotos reais |
| Tamanho da prova | |
